# VK to Telegram Reposter Bot

бот на **Rust** для автоматического репоста записей из сообщества ВКонтакте в канал Telegram.

## Особенности
- **Поддержка медиа**: 
  - Текстовые посты.
  - Одиночные изображения с сохранением подписи.
  - Автоматическая группировка нескольких картинок (до 10) в **медиа-альбомы (галереи)** Telegram.
  - Автоматический перенос длинного текста (>1024 символов) отдельным сообщением.
- **Защита от дублей**: бот сохраняет ID последнего опубликованного поста в `last_post_id.txt`.
- **Игнорирование старых постов**: при первом запуске бот запоминает актуальный ID и не спамит историей.

## Стек технологий
- [Rust](https://www.rust-lang.org/)
- [telers](https://github.com/Desiders/telers) — Telegram Bot API фреймворк
- [tokio](https://tokio.rs/) — асинхронный рантайм
- [reqwest](https://github.com/seanmonstar/reqwest) — HTTP-клиент


Настройка (.env)

Заполните данные в файле .env:

BOT_TOKEN — токен от @BotFather.
TG_CHANNEL_ID — канал (@channel_name или -100xxxxxxxxxx).
VK_ACCESS_TOKEN — сервисный ключ доступа приложения ВК (dev.vk.com). Необходимо будет создать приложение и получить сервисный ключ в настройки > разработка > ключи доступа.
VK_GROUP_ID — числовой ID сообщества ВК (publicXXXXXXXXX из настроек, где XXXXXXXXX — айди (нужно только число)).
CHECK_INTERVAL_SECS — интервал проверки (по умолчанию 1800 сек = 30 мин).
